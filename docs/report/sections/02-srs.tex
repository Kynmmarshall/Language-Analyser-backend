\section{Software Requirements Specification}\label{part:srs}

\subsection{Purpose and intended audience}

This part states what Francanglais Studio must do, independently of how it is built. It
is written for the course examiner assessing the deliverable, and for any future
contributor who needs to change the system without re-deriving its obligations. Design
and implementation choices are deferred to Part~\ref{part:sdd}.

\subsection{Constraints and assumptions}

\begin{description}[leftmargin=1.4em, style=nextline, font=\bfseries]
  \item[Single target variety]
    The analyzer accepts Cameroonian Francanglais only. The target is fixed in code as
    \texttt{TARGET\_VARIETY}; requests naming any other variety are refused rather than
    silently analysed under the wrong specification.
  \item[No parser generator]
    The scanner, lexer and parser are written by hand. Using \texttt{lex}/\texttt{yacc}
    would hide precisely the transformations the coursework assesses.
  \item[One token of lookahead]
    The parser is LL(1) by construction. Any grammar rule that cannot be expressed within
    that limit must be reported as a limitation rather than worked around.
  \item[Ethical collection]
    Speakers are informed and consent obtained before identifiable conversation is
    retained; records carry collector identifiers rather than speaker identities.
  \item[Assumption]
    Collectors are familiar enough with Francanglais to transcribe accurately, and a
    second member independently checks each transcription.
\end{description}

\subsection{Acceptance criteria}

The system is considered to meet its requirements when: the corpus contains at least ten
manually attested field statements, each attributable to a collector (\req{FR-1}--\req{FR-7});
the constructed parsing table contains no conflicting cell (\req{FR-22}, \req{NFR-3});
every collected statement receives an explicit accept or reject verdict with a derivation
or an expected-terminal set (\req{FR-24}--\req{FR-26}); and the full automated suite
passes. Section~\ref{sec:verification} reports the measured outcome against each of these.
