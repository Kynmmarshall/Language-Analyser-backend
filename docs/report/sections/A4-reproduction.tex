\section{Reproducing This Report}\label{app:repro}

Every table and figure is generated from the running system. Nothing is transcribed by
hand, so the document cannot drift from the software it describes (\req{NFR-8}).

\subsection{Build}

\begin{lstlisting}[language=bash, numbers=none]
cd docs/report
pwsh ./build.ps1
\end{lstlisting}

That performs three steps in order:

\begin{enumerate}[leftmargin=1.4em, itemsep=0.15em]
  \item \texttt{tools/export\_tables.py} --- re-exports every data table in
        \texttt{generated/} directly from the analyzer.
  \item \texttt{tools/render\_diagrams.py} --- renders \texttt{diagrams/*.puml} to
        \texttt{figures/*.png} via the PlantUML server.
  \item \texttt{latexmk -pdf main.tex} --- compiles this PDF.
\end{enumerate}

To publish from a live corpus database instead of the bundled specification:

\begin{lstlisting}[language=bash, numbers=none]
python tools/export_tables.py --database sqlite:///../../data/app.db --field-only
\end{lstlisting}

Application screenshots (Appendix~\ref{app:screens}) are captured separately, from the
front-end repository, by driving a real browser against the running service:

\begin{lstlisting}[language=bash, numbers=none]
node scripts/capture-report-screenshots.mjs
\end{lstlisting}
