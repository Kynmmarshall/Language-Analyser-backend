\section{Application Screenshots}\label{app:screens}

The captures below are taken from the running application by the script
\texttt{capture-report-\allowbreak screenshots.mjs} in the front-end repository, which drives
a real browser against the live service at 1680\,px and 2$\times$ pixel density. They are
not mock-ups, and they are regenerated by re-running that script.

\screenshot{shot-analyser.png}{Analyser view --- accepted statement}
{\fw{Combi va au kwatt.} analysed end to end. The token stream resolves to
\term{NOUN VERB PREP NOUN}, with \fw{combi} and \fw{kwatt} flagged as slang; the verdict is
\accepted; and the topic rule reports \term{commuting}, citing the word that triggered it.}

\screenshot{shot-tokens.png}{Token inspection}
{An expanded token row showing the canonical form, terminal class, part of speech, donor
language and gloss --- the lexicon provenance described in Section~\ref{sec:lexical}, readable
without leaving the analysis.}

\screenshot{shot-rejected.png}{Analyser view --- rejected statement with repair suggestions}
{\fw{Le resau ne passe pas.} is \rejected\ with reason \term{lexical unknown token}, because
\fw{resau} resolves to \term{UNKNOWN}. Pressing \emph{Suggest a fix} runs
\texttt{core/suggest.py}, which recovers the intended \fw{réseau} despite the missing accent
because candidate matching runs over folded forms. Note the disclaimer the interface itself
prints: the advice is derived from the parser's own error report, not from a language model,
so the same input always yields the same advice.}

\screenshot{shot-grammar-original.png}{Grammar explorer --- original and transformed rules}
{The authored left-recursive grammar beside its mechanically transformed LL(1) equivalent,
with the interface explaining why the rewrite is necessary.}

\screenshot{shot-ledger.png}{Grammar explorer --- transformation ledger}
{The \LedgerSteps\ recorded steps, each naming the rules consumed and the rules produced.
This is the audit trail reproduced as the ledger table in Section~\ref{sec:syntax}.}

\screenshot{shot-ll1-table.png}{Grammar explorer --- LL(1) parsing table}
{The constructed table as the interface presents it, inside a scrolling pane: rows are
nonterminals, columns are terminals, and each cell names the production to apply. The blank
cells are where a syntax error is detected. Only the leading columns and rows fit on screen;
the complete table appears in Section~\ref{sec:syntax}.}

\screenshot{shot-lexicon-search.png}{Grammar explorer --- lexicon search}
{Incremental search filtering the \LexiconTotal\ entries as the user types, with a live
match count. Searching without accents still reaches accented entries.}

\screenshot{shot-corpus.png}{Corpus manager}
{The statement list with per-record \texttt{source\_kind}, revision number, publication state
and detected topics. Statement identifiers and collector identity are assigned server-side,
and \emph{History} exposes the append-only revision trail.}
